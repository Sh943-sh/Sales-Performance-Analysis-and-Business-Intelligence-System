Project: Sales Performance Analysis and Business Intelligence System

Project Overview and Approach: Transformed raw, unstructured mobile sales data (separate day/month/year fields, inconsistent day names) into a clean, structured dataset using Power Query (ETL), built a custom date calendar for accurate time-based calculations, and designed an interactive multi-page Power BI dashboard with KPIs, maps, trend charts, and DAX-driven insights (MTD, QTD, YTD, Same Period Last Year).

Tools/Methods/Frameworks: Power BI Desktop, Power Query (M language/ETL), DAX (SUMX, CALCULATE, TOTALMTD/QTD/YTD, SAMEPERIODLASTYEAR), data modeling (star schema with fact/dimension tables), Power BI Service (publishing & sharing).

Result/Impact: Delivered a single-source, real-time dashboard enabling stakeholders to track ₹769M+ in total sales, 19K+ units sold, and 3,835 transactions across regions, brands, and payment methods — with drill-down time intelligence (MTD/QTD/YTD/YoY) that replaced manual Excel reporting and cut analysis time significantly.
